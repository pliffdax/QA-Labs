## Структура

- У кожній папці лабораторної зберігаються код, команди, результати виконання та скриншоти.
- `report.pdf` — копія готового звіту для перегляду та здачі.
- Робочі файли Docex залишаються в навчальній структурі на комп'ютері й не дублюються в Git.
- [`labctl.py`](labctl.py) створює ізольований мережевий стенд для лабораторних робіт у Linux network namespaces.
- В опублікованій історії Lab01 приховано випадково введений пароль; решту невдалих команд і виправлень збережено.

## Запуск мережевого стенда

На Ubuntu:

```bash
sudo python3 labctl.py setup
sudo ip netns list
```

Після завершення роботи:

```bash
sudo python3 labctl.py cleanup
```
